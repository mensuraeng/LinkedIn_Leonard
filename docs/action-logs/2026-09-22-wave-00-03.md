## Objetivo

Implantar a fundação obrigatória antes de qualquer integração ou write real no LinkedIn:

```text
Mission → Policy → Approval → Mock Gateway → Verification → Audit
```

## Mudanças integradas

- `PolicyEngine` fail-closed com `GLOBAL_WRITE_ENABLED=false` por padrão;
- `ApprovalGate` vinculado a ação, conta, payload canônico, hash e expiração;
- `AuditLog` append-only, com trace `TRACE-LNK-YYYYMMDD-XXXX` e metadados sanitizados;
- `MockLinkedInGateway` com idempotência, colisão de chave e falhas simuladas;
- `MockVerificationBoundary` distinta do gateway; sucesso de gateway sem verificação não confirma missão;
- bloqueio de substitutos/subclasses de gateway antes de qualquer I/O;
- simulador adversarial para policy, approval, kill switch, 401/403/429/timeout, mismatch, not-found e idempotência.

- OAuth, token, cookie ou credencial;

- publicação, comentário, mensagem, reação ou qualquer write externo;
- banco, fila, Córtex write ou integração de produção.
